# Gonçalo Gomes

Applied AI and machine learning researcher at **Instituto de Telecomunicações**, and PhD candidate with a background in Electronics and Telecommunications Engineering.

My work combines deep learning and signal processing with LLM-based systems for scientific document analysis and engineering workflows. I develop and evaluate these systems with attention to experimental integrity, traceable evidence and explicit limitations.

## Representative Projects 

| Project | Focus |
| --- | --- |
| [Drone RF Classifier](https://github.com/GoncaGomes/drone-rf-classifier) | A compact PyTorch CNN for raw-IQ signal classification, with recording-disjoint splits, a synthetic demo and documented experiment provenance. |
| [Antenna Paper Extraction](https://github.com/GoncaGomes/antenna-paper-extraction) | Agent-based extraction of antenna architecture from scientific papers, producing evidence reports and execution traces. The experimental MCP workflow is available on the [development branch](https://github.com/GoncaGomes/antenna-paper-extraction/tree/exp/architecture-mcp). |
| [MCP PDF Ingestion](https://github.com/GoncaGomes/mcp-pdf-ingestion) | A PDF evidence server adapted from an existing reviewer project, exposing deterministic retrieval tools and explicitly requested visual inspection through MCP. |
